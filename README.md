# Gankly test releases

Download the Windows x64 installer from [the latest release](https://github.com/zSkanz/gankly-releases/releases/latest).

Installed copies automatically check for signed updates and show an Update Gankly button. Updates are installed only after a click.

This is an early test build. Read each release notes before playing. Auto-pick preview and lock currently have known failures; always be ready to select manually.

The test installer has no Windows Authenticode certificate. Updater authenticity uses a separate signature verified by Gankly.
